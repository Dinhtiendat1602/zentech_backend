# zentech_backend

Backend RESTful API & Socket server cho hệ thống thương mại điện tử ZenTech (Node.js, Express, Sequelize, PostgreSQL).

## Cài đặt & Khởi chạy

```bash
# Cài đặt thư viện
npm install

# Tạo file cấu hình từ .env.example
cp .env.example .env
# Cập nhật thông tin PostgreSQL, JWT_SECRET và SMTP trong file .env

# Khởi chạy server ở chế độ development
npm run dev

# Khởi chạy production
npm start
```
